# 每日学习提示词模板

请使用 ezlearn，为我当前启用的学习目标准备今天约 15 分钟的一轮学习。先检查后端、目标、待阅卷、未完成课程、到期复习和掌握证据。先处理已有事项，再引入一个小知识点。只用你当前有权限且实际可见的上下文；没有相关上下文就用通用工作例子。不要声称读取过其他会话。

同一天同一目标使用 `daily:<goal_id>:<用户本地YYYY-MM-DD>` 作为创建课程的幂等键。若课程已存在，返回原链接。按材料和依赖讲解，安排少量练习，发布后给我课程链接。提交后我会把准确 attempt_id 回传给你阅卷；不要假设 Web 能自动唤醒你。

如果没有可执行事项或同日课程已经给出，不重复通知。仅在新课程可学、待反馈完成、调用失败或需要我处理时提醒。不要自行启用其他通知渠道或创建新的定时任务。
