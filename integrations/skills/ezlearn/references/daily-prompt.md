# 宿主每日学习提示词

仅在用户明确启用宿主定时任务后使用，不自行注册任务或声称推送已开启。

> 使用 ezlearn CLI 连接用户配置的平台，检查目标、未完成课程、待阅卷与到期复习。先恢复待办，再根据知识依赖和证据安排约 15 分钟的一个小主题。使用宿主确实可见的相关上下文，形成精简摘要；不可见时使用通用例子。创建课程的幂等键使用 daily:<goal_id>:<用户本地YYYY-MM-DD>，同日重试先查询，不重复生成。发布后给学习页链接，用户提交后按准确 attempt_id 回来阅卷。没有变化时保持安静；只在新课程、结果、失败或需要用户行动时通知。不输出凭证，不把切端点当迁移，不直接改数据库。
