# 剩余注意力理论

“剩余注意力理论”是项目发起者提出的指导理论，名称暂定。本文将其整理为待实践检验的产品假设，用于说明 ezlearn 为什么存在，以及约束产品与教学设计。

## 核心定义

> 剩余注意力以用户已经投入的注意力为参照。用户已经在某项活动中形成上下文，ezlearn 从这一现实起点出发，寻找用户仍愿意且能够用于学习的注意力，通过降低情境转换和学习组织的负担，帮助用户完成有意义的小步学习。

这个定义从“已经投入的注意力”出发，不要求先假定用户拥有一份完整、可自由支配的“全部注意力”。“剩余”表达的是与既有投入的关系，不能直接写成“总注意力减去工作注意力”的余额公式。

已经投入的注意力既构成约束，也留下了可承接的背景、问题和例子。平台希望借助这些已有条件，在用户愿意开始学习时，减少额外准备与切换负担。

## 项目要解决的问题

本项目采用的设计起点是：人能够调配的注意力有限，重新建立上下文存在成本。一次学习除了理解知识，还可能要求用户选择课程、说明背景、找回进度，以及决定下一步做什么。这些准备也会消耗学习投入。

ezlearn 将这些组织工作交给 Agent 与平台协作完成。Agent 结合实际可见的上下文编排一小步教学；平台保存学习依据、课程、作答和反馈，使这一步能够继续、重看和积累。用户无需每次从头组织一轮学习。

有一段空闲时间，并不意味着用户愿意或能够学习；同一时长下适合承接的学习任务也可能不同。平台不能仅凭空闲、在线或正在等待，就判断存在可利用的注意力。沿用上下文的教学仍需要用户主动理解和练习。

## 对产品的约束

1. **从已有情境接入。** 使用当前对话可见或用户主动提供的背景，减少重新解释背景的要求。可见信息不足时采用通用例子，不推定平台能够读取其他会话或自动测量注意力。
2. **学习目标保持稳定。** 学什么由用户目标、前置知识和学习证据决定；已有情境帮助决定怎样解释。最近的工作可以提供例子，不能任意替换用户的学习目标。
3. **控制新增负担。** 每轮围绕一个小知识点，提供明确的下一步。10～20 分钟是默认教学规模，不表示用户一定拥有相应注意力；允许暂停或结束，并保存必要的恢复信息。
4. **按教学需要选择媒介。** 图片、音频和视频用于帮助理解、演示和练习，组织方式应让用户容易进入内容。媒体数量、动效和刺激程度不能代替教学价值。
5. **让开始与恢复都容易。** 优先接续未完成课程，保留草稿和必要背景，减少再次选择与回忆。开始、继续和结束由用户决定，提醒沿用明确启用的规则。
6. **用学习证据判断价值。** 讲过或看过只记录接触；掌握情况仍依据实际练习与评价。停留更久、看更多视频或完成更多点击，不能直接等同于学会。

## 一个例子

用户已经在与 Agent 排查请求失败和重试问题，同时有英语学习目标。用户希望开始一轮学习时，老师可以沿用这个熟悉情境，用 “If the request fails, we will retry it.” 解释条件表达，再安排少量判断与改写练习。

学习目标来自英语学习计划，例子承接刚才的工作情境。用户继续投入理解和作答，平台保存原课与反馈，使下一轮可以从已有证据继续。

## 如何检验

后续通过用户反馈与实际学习结果检验这一假设：是否更容易开始，是否减少重复说明背景和选择内容，暂停后是否容易恢复，以及练习能否形成持续的学习证据。这些是待验证的问题；当前产品没有注意力测量器或相关统计能力。

简短表达：**ezlearn 从用户已经投入的注意力出发，让下一小步学习更容易发生。**
