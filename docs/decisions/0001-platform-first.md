# 决策 0001：独立学习平台与实例管理 CLI

状态：已接受，2026-10-26。本文更新启动提示词中的旧形态；原始启动文档作为历史设计输入保留。

ezlearn 是一个可独立运行、自部署的个人 Web 学习平台，负责学习内容与版本、目标、课程、作答、评价、学习证据和复习。外部 Agent 是可替换的老师；GitHub 仓库是初期学习包的主要分发渠道，不开发学习包市场。

## 边界

- 平台独立启动、提供 Web 和 HTTP API，拥有数据库、学习包下载/校验/版本管理、认证、数据导入导出与版本生命周期。
- CLI 管理本地实例的启动与诊断、保存并切换端点、处理连接与凭证，并提供平台操作的终端入口。学习业务命令始终经 HTTP，包括本机平台；连接失败不回退到数据库直连。
- Skill 是 CLI 操作指南和简短教学工作流，不承担评分或状态一致性。课程与主观题反馈由 Agent 形成，由平台校验并保存。
- 本地与云端的客户端配置统一为 endpoint 和凭证引用，profile 名称仅方便切换。切换端点不等于迁移数据。
- MCP 退出本阶段默认产品与发布依赖，有真实接入需求后再作为同一 API 的适配层评估。

## 本阶段可验收内容

1. 平台可脱离 CLI 用独立入口启动；保留 `ezlearn start` 作为本地生命周期便捷命令。
2. CLI 学习命令使用统一 HTTP 客户端；具备命名端点配置、切换和诊断。旧 profile 可显式兼容迁移，既有 SQLite 学习数据不变。
3. 本地平台生成实例凭证，CLI 从匹配端点的实例连接文件读取；远端使用环境变量引用。Web 学习接口不暴露教师答案键，教师 HTTP 请求校验真实凭证。
4. 平台负责从 GitHub 指定 ref 解析与安装学习包；Web 可上传纯数据包、安装 GitHub 包和查看已安装版本，不依赖 CLI 完成包管理。
5. 端点切换、服务未运行、认证失败、包安装、完整学习与阅卷、重启持久化及原有迁移均有实际验证。

## 后续阶段

发布可下载的版本产物与安装器；建立平台升级检查、备份、数据库迁移、失败恢复与回滚流程后，再实现可选择启用的自动升级。当前从源码构建与启动，不宣称已提供一键安装、在线升级、后台进程监管或自动推送。

多云存储适配保留为平台内部实现。当前有界聚合 1,500,000 字节限制继续公开；分表扩容单独推进，不与客户端协议重构混做。
