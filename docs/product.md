# 产品与范围

ezlearn 是一个可独立运行、自部署的个人 Web 学习平台。用户安装学习包、建立目标，每次花 10～20 分钟完成“学一点 → 做几题 → 得到反馈 → 保存证据 → 下次继续”。默认中文、单用户、本地优先。

用户已有的 Agent 可以担任老师，负责选择实际可见的上下文、编排短课和提供主观题反馈。平台拥有内容、规则和记录，既不依赖某一宿主，也不要求配置 LLM API Key。目标、考纲、前置知识和作答证据约束选题，最近的工作只改变例子和切入点。

## 四个边界

| 部分 | 责任 |
| --- | --- |
| 平台应用 | 学习包下载/校验/版本、目标、课程、作答、评价、证据、复习、认证、数据迁移与应用生命周期 |
| Web | 阅读、答题、草稿、反馈、历史、目标设置与学习包管理 |
| CLI | 本地实例启动/诊断、端点配置/切换，以及平台操作的终端入口；学习命令全部走 HTTP |
| Skill | CLI 使用说明与简短教学流程；引导 Agent 查状态、备课、发布、阅卷和结束 |

平台可以脱离 CLI 独立启动。CLI 连接哪个实例，就操作哪个实例的学习数据；切换端点不触发迁移。学习包属于安装它的平台，云实例不能依赖 CLI 所在电脑的目录。

## 学习包与课程

学习包是版本化的学习依据，说明范围、知识结构、材料和评价标准。初期主要以 GitHub 仓库分发，也接受纯数据文件上传，不建设市场或交易系统。平台负责解析 ref、记录实际 commit、校验并保存版本。

课程是老师根据某个用户的目标和进度形成的一轮教学实例。Agent 可以生成情境例子与补充练习；这些内容连同答案、rubric、引用和来源类型保存为课程快照，不自动改写原包。当前格式 v1 要求完整材料、题库和蓝图；更轻的内容包属于后续格式演进，不能拿文档愿景冒充已支持的 schema。

English Demo 用开发场景展示流程。它不是四六级官方考纲、真题或完整备考课程，不能据此承诺考试成绩。

## 一轮学习

老师先恢复未完成课程，处理待阅卷，再安排到期复习或新知识。课程包含一个小目标、一段讲解、熟悉的工作例子、材料引用和少量练习。上下文不可见时使用当前会话、用户提供的简短背景或通用例子，不扫描其他 Agent 的历史目录。

用户通过 Web 保存草稿、刷新继续并提交。平台将作答标记为 submitted，提供含准确 attempt_id 和实例地址的交接提示词。用户复制给老师，老师读取绑定的原题、答案键、rubric 和材料，写回逐题反馈。平台不主动唤醒 Agent。

单选由平台按答案键计算；简答由老师依 rubric 评分，平台校验题目、范围和反馈。讲过只记录曝光；完成评价的练习才形成能力证据，未摸底保持 unknown。当前是公开规则的复习安排，不宣称实现 FSRS、BKT 或考试通过率预测。

## 当前阶段与范围

v0.2.0 第一阶段收敛独立平台、统一 HTTP、实例配置和平台内学习包管理，移除 MCP 默认路径。既有 SQLite 数据、发布快照和逻辑迁移格式继续保留。容量与运行时差异见架构文档。

应用的发布、升级、备份、迁移和回滚属于完整平台生命周期。当前仍从源码构建启动，下载安装、升级检查和可选自动升级按[路线图](roadmap.md)分阶段实现。

暂不提供团队、多租户、内容市场、二进制附件、自带模型聊天、跨 Agent 原始历史导入、实时双向同步、手机推送或社交。用户可随时结束；提醒只在用户明确启用后交给宿主，项目仅提供提示词和每日幂等键。
