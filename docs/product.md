# 产品与范围

ezlearn 让用户已有的 AI Agent 担任老师，把熟悉的工作情境变成学习例子。目标是每次花 10～20 分钟，完成“学一点 → 做几题 → 得到反馈 → 保存证据 → 下次继续”。默认中文、本地优先、单用户，平台不要求 LLM API Key。

用户通常有技术背景，习惯 CLI、Skill 和 MCP。第一次说 `/ezlearn 我要学英语，每天 15 分钟` 时，老师先检查目标与学习包，只补问真正缺失的信息。英语考试目标仍需适配考纲的学习包；English Demo 仅演示系统功能，不能用来承诺考试成绩。

## 每轮学习

老师先恢复未完成课程，处理待阅卷作答，再考虑到期复习、新知识。上下文只决定例子与切入点，选题必须服从目标、包内依赖和既有答题证据。无法读取其他会话时，用当前会话、用户简短补充或通用工作场景；不扫描其他 Agent 的历史目录。

课程包含一个可做到的小目标、一段讲解、工作情境例子、材料引用和少量练习。Web 提供阅读、服务端草稿、提交、反馈与历史。用户提交后会看到准确的 `attempt_id` 与后端标识，复制交接提示词回老师。平台不主动唤醒 Agent。

单选题由平台按答案键计算；简答题由老师依 rubric 给分并反馈。老师不能覆盖客观答案键。讲过的知识记录 exposure，练习证据来自完成评价的作答；未摸底的能力保持 unknown。首版是公开规则的复习安排，没有实现 FSRS、BKT 或通过概率预测。

## v0.1 边界

本地使用显式 `ezlearn start`，不安装守护进程。Cloudflare 与 Vercel 使用同一业务核心和有认证的远程 HTTP MCP。云端部署需要用户自己的账号、数据库和密钥，不由项目脚本自动创建付费资源。

首版支持单选和简答、纯文本材料、包版本快照与迁移到空实例。不提供二进制附件、内容市场、团队、多租户、自带大模型聊天、跨 Agent 历史导入、实时双向同步、手机推送或社交功能。单用户存储采用明确有界的 SQL 聚合快照，容量说明见架构文档。

用户可随时结束学习。提醒由宿主在用户启用后安排，本项目只提供可重复调用的提示词与幂等键约定。
